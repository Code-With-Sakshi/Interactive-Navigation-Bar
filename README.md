# Interactive Navigation Bar

This project demonstrates an interactive and responsive navigation bar with the following features:
- **Hover effects**: Menu items change style when hovered.
- **Scroll behavior**: Navbar background changes color when the user scrolls.
- **Fixed position**: Navbar stays visible at the top while scrolling.
- **Reusable menu**: Same navbar can be used on multiple pages.

## Files
- `task1.html` → Main HTML structure  
- `task1.css` → Styles for the navbar and page  
- `task1.js` → JavaScript for interactive behavior
